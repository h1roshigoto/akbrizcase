Administrative statistics

Last 30 UTC days

Calendar days include both boundaries in UTC. Counts describe only data still stored at query time. Retention and deletion can reduce these counts; deleted data is never reconstructed. An order that survives personal-data erasure remains counted.

Order status, session mode and outcome are current values, not immutable historical events. Handoff is a referral to a specialist. Resolved records explicit accepted positive feedback. Neither handoff nor a created order means a sale, payment or revenue.
