# Frontend — MVP-054

Минимальное React + TypeScript + Vite приложение со стартовой страницей
«B2B-портал». Backend, БД и переменные окружения не требуются.

Требуются Node.js **24.19.0** и npm **11.9.0**. Версия Node.js указана
в `.nvmrc`; при использовании nvm выполните `nvm install` и `nvm use`
из `frontend/`. Поддерживаемые диапазоны заданы в `package.json`.

Из корня репозитория:

```sh
cd frontend
npm ci
npm run dev
```

Откройте адрес из вывода Vite (по умолчанию <http://127.0.0.1:5173>).
Остановка сервера — Ctrl+C.

Проверка типов и production-сборка из `frontend/`:

```sh
npm run typecheck
npm run build
npm run preview
```

`build` сначала выполняет typecheck, затем создаёт статику в `dist/`.
`preview` открывает эту сборку по адресу из вывода Vite (по умолчанию
<http://127.0.0.1:4173>). Для smoke-проверки оставьте backend выключенным:
страница должна показывать заголовок «B2B-портал» без ошибок JavaScript
и обращений к API. Preview предназначен для локальной проверки сборки.

Прямые зависимости закреплены точными версиями, транзитивные зависимости
и integrity-хэши — в `package-lock.json`. Используйте `npm ci` для установки
из lockfile; команда воспроизводит установку и в пустом `node_modules/`.
Обновления зависимостей требуют обновления lockfile и повторных проверок.

TypeScript работает в strict-режиме, включая проверку индексированного
доступа, optional-полей и неиспользуемого кода. Проверяются `src/` и
`vite.config.ts`. В приложении нет API-клиента, бизнес-данных, маршрутизации,
авторизации, каталога, формы или чата; контракты относятся к MVP-002.

Секреты и `.env` для запуска не нужны. Всё включённое в клиентский код
и используемые переменные `VITE_*` доступно посетителю в bundle:
не помещайте туда ключи, пароли и другие чувствительные данные.
`node_modules/`, `dist/` и локальные `.env*` исключены из git.
Compose, Nginx, worker и CI относятся к следующим задачам.
