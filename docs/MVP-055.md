## Состав и запуск

- `nginx`: статика React; `/healthz` и `/api/…` → FastAPI, путь сохраняется.
  Единственный опубликованный порт: `127.0.0.1:8080`.
- `api`: Uvicorn/FastAPI, внутренний 8000, UID/GID 10001.
- `worker`: тот же image ID, stdlib idle-процесс, без бизнес-операций и БД.
- `postgres`: `postgres:16.13-bookworm`, внутренний 5432, постоянный volume.

`web` и `data` — internal-сети. Nginx не подключён к `data` и не получает
file-volume/DB-secret. API/worker имеют закрытый `app_files`, режим 0700.
Точный набор базовых тегов: Python 3.12.14, uv 0.12.23, Node 24.19.0,
Nginx 1.28.3-alpine, PostgreSQL 16.13-bookworm; runtime-пароль не участвует
в сборке. Пароль получает только PostgreSQL; приложению до MVP-003 он не нужен.

```sh
cp .env.example .env
make init-secrets
make config
make up
make smoke
make stop
make down
```

Полные инструкции clone, требований к инструментам, смены порта и секретов —
в [README.md](../README.md). Стандартные команды сохраняют volumes.

исправлены, приведены результаты повторных проверок итоговой конфигурации.

## Ограничения

- Только HTTP на loopback и синтетическое демо. Production TLS/HTTPS,
  backup/restore, публичный deploy и допуск к реальным данным не заявляются.
- API health — liveness. DB driver/roles для приложения, readiness схемы,
  миграции и UoW относятся к MVP-003. Bootstrap-владелец PostgreSQL не выдаётся
  приложению. Smoke создаёт только техническую таблицу в одноразовом volume.
- Worker не обрабатывает outbox, письма или ПДн. Redis/Celery/MinIO и отдельного
  ClamAV-сервиса нет. Бизнес-функции не добавлены.
- Runtime secrets Compose — файлы хоста, не secret manager. Оператор Docker
  имеет доступ к volumes. Изменение файла не ротирует пароль существующей БД.
- Проверена Linux x86_64; другие платформы не проверялись. Теги фиксируют
  версии, но не являются immutable digest; обновления требуют повторного smoke.
- GitHub Actions не добавлены: это MVP-056. Автоматический merge не выполняется.
